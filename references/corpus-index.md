# TPAMI: 100 recent AI papers

Collected and checked on **22 October 2026**. Window: **22 October 2024–22 October 2026**. This is a purposeful, topic-balanced sample, not an exhaustive or random sample. Dates below use the formal issue date when available and an indexed online/Early Access date otherwise. Earlier online dates can differ.

All 100 records match by DOI in Crossref and Europe PMC; OpenAlex provides a third metadata and repository check. Full-text status is explicit: 42 repository PDFs were retrieved, 19 with explicit TPAMI-version evidence were used for section-structure inspection. The remaining records support bibliographic and abstract-level analysis.

The CSV includes full metadata, abstracts, reported date fields, open-access links, and evidence status. The BibTeX file contains the 100 journal citations.
